## 아직 확인하지 않은 운영 단계

- Docker Desktop Linux 엔진이 실행 중이지 않아 실제 이미지 빌드·컨테이너 재시작은 미검증이다. 영구 볼륨 구성과 앱 재시작 시 보존은 각각 구성 검사·HTTP 검사로 확인했다.
- Supabase 프로젝트가 아직 없어 실제 가입 이메일·로그인·토큰 갱신을 연결한 확인은 남아 있다. 인증 응답을 모의한 계정 분리 검증과 실제 검증 함수의 실패 처리는 통과했다.
- 외부 호스팅 계정·도메인·HTTPS는 아직 연결하지 않았다. 현재 주소는 이 PC의 로컬 데모다.
- 최종 요청 위치 `D:\AI project\MD_Decision_Lab_v2`의 쓰기 권한이 허용되지 않아 C드라이브 임시 V2에서 개발했다. D드라이브 이동은 남아 있다.

실제 Supabase 연결 후에는 신규 계정 두 개로 서로의 자료가 보이지 않는지, 이메일 인증과 로그인 복구가 되는지 확인한 뒤 공개한다. 기존 회사 자료나 H&M 원본을 공개 시연 DB로 옮기지 않는다.
